# 洛洛的手机

给周棋洛（《恋与制作人》）做的私人留存站：整站是一部手机，每个板块是里面的一个 App。

- **剧情**：一段一段补回来的时间线。拖左侧手柄（或点 ↑ ↓）自由调整前后顺序；每段有进度（看过了 / 正在补 / 想看）、评分、重温次数、截图、摘抄和感想。
- **朋友圈**：直接放截图，一次可以选很多张，每张存成一条。
- **通话**：电话、短信、语音；可以放截图、录音和文字稿。
- **卡册**：羁绊卡面收藏。
- **同人**：收藏的二创，记作者和出处。
- **语录**、**纪念日**（自动倒数）。
- **桌面**：只做装饰。设置 → 装饰桌面，可以摆贴纸、放自己的免抠素材（可加白边）、换壁纸；右上角太阳 / 月亮切换白天和夜里（Key）。

## 内容存在哪

默认只存在当前浏览器里。设置 → 同步，填上你自己的**私有** GitHub 仓库和一个只对它有 Contents 读写权限的 fine-grained 令牌后，手机和电脑会自动同步。令牌只保存在本机浏览器，不会进这个仓库。设置里还可以导出 / 导入完整备份，删除的东西先进回收站。

站里不自带任何官方图片，图片都由使用者自己上传，保存在使用者自己的私有仓库。

## 开发

```
npm install
npm run dev      # 本地预览
npm run build    # 生成 docs/，GitHub Pages 从 main 分支的 /docs 发布
```

源码在 `src/`：`store.ts`（数据、同步、备份）、`kinds.ts`（各板块的字段）、`screens.tsx`（各板块的页面）、`App.tsx`（桌面、装饰、设置）、`art.tsx`（原创贴纸和图标）、`style.css`。
